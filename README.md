
### HƯỚNG DẪN SỬ DỤNG GIT
Cài đặt ban đầu: git init <br>
Thêm toàn bộ tệp đã chỉnh sửa: git add . <br>
Commit để đưa toàn bộ nội dung chỉnh sửa vào git: git commit -m "first commit" <br>
Lệnh này chỉ cần cài đặt lần đầu: git branch -m devel <br>
Lệnh này cũng chỉ cần cài đặt lần đầu: git remote add origin https://github.com/phanmemthptdinhlap/rpy.git <br>
Đẩy toàn bộ nội dung chỉnh sửa lên máy chủ: git push -u origin devel <br>
